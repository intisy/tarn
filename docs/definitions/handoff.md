# HANDOFF

`HANDOFF.md`: where work stands now, so a cold session can resume.

- **For:** what is true now, what is next, and what a cold session must not do.
- **Reader:** the next session.
- **Kind:** current only. History does not live in it.
- **May appear:** once per org docs tree, in the records half. Never in a repo docs tree.

## Rules

1. It is pruned on every write: a sentence that no longer holds is deleted, not corrected beside.
2. Anything still binding moves first to `DECISIONS.md`, `FAQ.md` or `RULES.md`, and only then is the sentence cut.
3. It names the open tasks it depends on by id and never restates them.
