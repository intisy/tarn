# DECISIONS

`DECISIONS.md`: the log of rulings with their grounds.

- **For:** answering "why is it this way" with the ruling, its date and what it rested on.
- **Reader:** anyone asking why.
- **Kind:** record, append-only.
- **May appear:** once per org docs tree, in the records half. Never in a repo docs tree.

## Rules

1. Each ruling is numbered and dated and carries its grounds.
2. An entry is not edited afterward. A reversal is a new entry that names the old one.
3. What is still binding is also stated in the current docs (the rules, the FAQ, the descent tree), which the log
   justifies and does not replace.
