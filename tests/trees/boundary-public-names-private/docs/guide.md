# Names

The secret repo intisy/secret holds it.
See [the design](https://github.com/intisy/secret/blob/main/design.md#part).
It moved from intisy/secret.
Not a name: intisy/secret-more, my-intisy/secret, intisy/secretive/x and intisy/public.
Bare https://github.com/Intisy/Secret?tab=readme is a name too.
Twice on one line: intisy/secret and [it](https://github.com/intisy/secret).
In code, `intisy/secret` is still published.
A path into it, intisy/secret/plans/x.md, names it.
So does a path that ends in it, GitHub/intisy/secret.
Case and a www host do not hide it: www.GitHub.com/intisy/secret/issues.

```text
intisy/secret
```
A clone of it, https://github.com/intisy/secret.git, names it.
So does a clone over ssh, git@github.com:intisy/secret.git.
Not a name: intisy/secret.github.
